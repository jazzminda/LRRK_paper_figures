# LRRK_paper_figures
This repository contains the Python and R scripts used to generate figures for the manuscript "Probing the cellular phosphoproteome and interactome of Leucine rich Repeat Kinases 1 and 2", available as a preprint on bioRxiv (https://doi.org/10.1101/2025.09.03.674114).

Repository contents

Script_Jansenetal_dataVisualization.ipynb: Python code for Figures 3, S1, S2, S6, S7 & S8.

clusterProfiler_script_Cluster.qmd: R/Quarto code for Figure S3.

Reproducibility

The code is provided to support transparency and reproducibility of the figures presented in the associated publication.
